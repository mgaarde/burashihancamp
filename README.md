# International JKA Bura Shihan Camp 2027

Event landing page and registration form. Visual design follows the SKA2026 website: SF Pro/system typography, warm white backgrounds, rounded cards, black buttons and Japanese ink artwork.

## Features

- Instructor information and training programme, 29–31 January 2027.
- Participant registration with training days, lunch and party selections.
- Price calculation and bank-transfer instructions.
- Restricted organiser view and CSV export.

## Development

React/Vinext project. Install dependencies, generate database migrations, and build before deployment. Configure administrator authorization through a server-side environment variable. Never commit credentials, participant records or environment files.

This is work in progress. Hosted registration, migrations and production deployment still need end-to-end verification before registrations open. No automatic confirmation email or card payment is included.

The image under public/assets is reused from the organiser's SKA2026 website. Other event details follow the supplied invitation.
